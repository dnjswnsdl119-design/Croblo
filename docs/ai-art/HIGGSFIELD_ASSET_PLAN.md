## Asset Inventory (현재 상태 = 전부 코드 생성 프리미티브/이모지이므로 "D. 신규 생성 필요"뿐)

|---|---|---|---|

| 던전(4개) 배경 | 단색 원형 바닥 + 실린더 기둥 | `buildArena()` 등 | D. 신규 생성 (바닥/벽 텍스처) |
| 환경 소품(나무/바위/횃불) | 원뿔/구/실린더 프리미티브 | `makeRock()`, `makeHouse()` 등 | D. 신규 생성 (소품 스프라이트) |

| Audio | Web Audio 합성음 | `SFX` 객체 | 범위 밖 (Higgsfield는 이미지/영상 도구이므로 오디오는 별도 논의 필요) |
| Cinematic/트레일러 영상 | 없음 | — | D. 신규 생성 (Higgsfield 영상 모델의 진짜 강점 — 게임 내 애셋이 아니라 마케팅용) |

## Higgsfield 적용 우선순위 (효과 큰 순서)

1. **플레이어 캐릭터 4종** — 화면에 항상 보이고, 게임 첫인상을 가장 크게 바꾼다.
2. **초반 필드 핵심 몬스터 3종** (고블린/늑대/오크) — 등장 빈도가 가장 높다.
3. **보스 5종** — 등장 빈도는 낮지만 임팩트가 가장 크고, 데모 티가 가장 많이 나는 지점(현재 보스도 색만 다른 캡슐).
4. **무기/방어구 등급별 아이콘 템플릿** — 인벤토리 화면에 상시 노출되는데 지금은 전부 동일한 이모지라 등급 구분이 텍스트 색상뿐임.
5. **나머지 필드/던전 몬스터 13종**
6. **마을 3종 + 던전 4종 배경 텍스처**
7. Elite/Affix 오라 오버레이, 환경 소품, VFX 개선 (여유가 있을 때)

## Higgsfield가 맡지 않는 것 (엔진/코드가 이미 잘 처리 중)

- 전투 판정, 데미지 계산, 크리티컬/회피 확률 — `getTotalStats()`, `playerAttack()` 등 순수 로직, 변경 불필요.
- 아이템 옵션/등급/세트 효과 — `SETS`, `RARITY`, `computeItemPower()` 등 완성도 높은 시스템, 변경 불필요.
- 몬스터 AI(추적/공격 쿨다운/보스 페이즈) — 순수 JS 상태머신, Higgsfield와 무관.
- 저장/로드 — `localStorage` 기반, 무관.
- 게임 밸런스(레벨링/드랍률/난이도) — 이번 세션에서 계속 다듬어온 수치 시스템, 시각 작업과 완전히 분리되어야 함.
- 스킬 로직/쿨다운/스킬트리 — 무관.

이 항목들은 지금 이대로 유지하고, 이번 아트 작업은 **오직 렌더링 레이어(스프라이트 텍스처 + 배경)**에만 손을 댄다.
