# 크로노스 소울 (Chronos Soul)

Three.js 기반 브라우저 아이소메트릭 액션 RPG. 디아블로 · 리니지 · 크로노스 온라인의 요소를 참고해 제작했습니다.

## 실행 방법

정적 HTML 파일 하나로 동작합니다. 로컬에서 간단한 정적 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000` 접속.

## 주요 기능

- 클래스 시스템 (파이터 / 새비지 / 발키리 / 마법사)
- 장비 강화, 세트/유니크 아이템, 룬 소켓 시스템
- 던전 2종 (오크 소굴, 심연의 균열) + 웨이브/보스전
- 퀘스트, 스탯 분배, 환생, 세계관/몬스터 도감
- 저장은 브라우저 localStorage 사용
